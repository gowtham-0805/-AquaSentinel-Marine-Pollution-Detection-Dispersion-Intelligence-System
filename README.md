# -AquaSentinel-Marine-Pollution-Detection-Dispersion-Intelligence-System
AquaSentinel is an AI platform detecting marine oil spills and plastic debris using Sentinel-1 SAR radar imagery ($\sigma^0$ backscatter) with 48h hydrodynamic advection-diffusion drift forecasting driven by wind and ocean currents. Features an interactive web app and Jupyter analysis notebook.
📌 Features

🛰️ SAR Processing & Backscatter Analytics: Analysis of Sentinel-1 C-band SAR images (VV/VH polarizations) to detect dark ocean patches (oil spills) and bright radar anomalies (marine debris).

🌊 Hydrodynamic Drift Simulation: Particle-based advection-diffusion modeling predicting 48-hour spill trajectory and time-to-coastal-landfall based on windage coefficients and current vectors.

📊 Interactive Jupyter Notebook (.ipynb): Machine learning prototype demonstrating image segmentation, backscatter signature extraction, and vector drift math.

💻 Interactive Front-End Web App (index.html): Interactive UI for image visualization, parameter adjustments, and instant risk reporting.
